# 450 prompts for text-to-video generation

Use these captions as generation inputs. No input video clips or video paths are required for text-to-video inference.
Choose a line from `prompts.txt` and pass it to `src/sora3_demo/generate_from_prompt.py` with `--prompt`.

These prompts do not fine-tune or teach the model by themselves. They are inference prompts for the pretrained CogVideoX model.
